# Viva questions and short answers

1. **What is Git?** A distributed version-control system that records source changes.
2. **Git vs GitHub?** Git is the version-control tool; GitHub hosts repositories and collaboration features.
3. **What is a branch?** An independent line of development.
4. **Why Gitflow?** It separates integration work (`develop`), features and releases (`main`).
5. **What is a merge commit?** A commit joining histories from two branches.
6. **What is rebase?** Replays commits on a new base; avoid rebasing shared branches.
7. **What is CI?** Automated checks on code changes.
8. **What is CD here?** Automated container publication and deployment verification.
9. **What is GitHub Actions?** GitHub's workflow automation service.
10. **What is GITHUB_TOKEN?** A short-lived workflow token with explicitly granted repository permissions.
11. **What is Docker?** A platform for packaging applications and dependencies into images/containers.
12. **Image vs container?** An image is the template; a container is a running instance.
13. **Why Compose?** It defines and runs the API, UI and database together.
14. **Why non-root Docker user?** It reduces container privileges.
15. **What is FastAPI?** A Python framework for typed HTTP APIs with OpenAPI documentation.
16. **What is an endpoint?** A URL and method that performs an API operation.
17. **What is SQLAlchemy?** A Python ORM and SQL toolkit.
18. **Why SQLite locally?** It works without separate database setup.
19. **Why PostgreSQL in Compose?** It demonstrates a production-style relational database service.
20. **What are z-scores?** Standardized differences from a reference distribution; here approximated for education.
21. **What is MUAC?** Mid-upper arm circumference, a measurement used in nutrition screening.
22. **Why synthetic data?** It allows repeatable testing without exposing real patient information.
23. **Why compare classifiers?** To compare candidate algorithms using a consistent split and metric.
24. **What is explainability?** Showing input indicators associated with a model or rule output; it does not prove causation.
25. **Is NutriTrack a diagnosis tool?** No. It is an educational screening aid and requires professional assessment.
